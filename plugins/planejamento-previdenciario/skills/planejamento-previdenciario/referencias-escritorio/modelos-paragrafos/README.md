# Modelos de Parágrafos e Trechos Reutilizáveis

Parágrafos e blocos de texto já validados em peças anteriores, prontos para
reaproveitar em casos futuros de qualquer matéria — diferente das subpastas
`previdenciario/`, `tributario/`, `civil/`, que guardam trechos de
lei/jurisprudência amarrados a uma tese específica de uma matéria.

Cada arquivo aqui reúne um tipo de parágrafo/pedido recorrente. Convenção de
nome: `[tema].md` (ex.: `justica-gratuita.md`, `tutela-de-urgencia.md`,
`pedidos-padrao.md`).

Dentro de cada arquivo, guarde:
- O texto do parágrafo/pedido já validado (com placeholders claros para os
  dados que mudam de caso para caso, ex.: `[NOME DO AUTOR]`, `[valor]`).
- Uma nota curta indicando em que tipo de peça/contexto ele já foi usado.
- Se houver mais de uma variação (ex.: uma versão para pessoa física
  hipossuficiente comprovada por declaração, outra para hipossuficiência
  presumida), mantenha as variações no mesmo arquivo, tituladas.

**Como a skill usa isso.** Na Etapa 8b (rascunho estruturado) e na Etapa 9
(redação da minuta), ao chegar em um trecho que corresponda a um dos temas
aqui guardados (justiça gratuita, tutela de urgência, pedidos padrão),
consulte o arquivo correspondente e adapte o modelo ao caso concreto, em vez
de redigir do zero. Se a matéria do caso tiver uma subpasta própria
(`previdenciario/[matéria]/modelos-paragrafos/`), o modelo específico da
matéria tem prioridade sobre o modelo geral daqui, quando os dois existirem
para o mesmo tema; use o geral como base e o específico como refinamento.

**Alimentando a pasta.** Só grave um novo parágrafo aqui (ou atualize um já
existente) com permissão explícita do usuário, seguindo o mesmo fluxo da
seção BASE DE REFERÊNCIAS DO ESCRITÓRIO da skill de peças (pergunta ao final
da Etapa 10, ou pedido direto do usuário fora do fluxo de uma peça, do tipo
"guarda esse parágrafo de tutela de urgência para reaproveitar depois").
Nunca sobrescreva um parágrafo já validado sem confirmação; se for uma nova
variação, acrescente ao arquivo em vez de substituir o que já existe.
